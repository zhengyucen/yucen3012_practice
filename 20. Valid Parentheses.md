## easy 20. Valid Parentheses
Example 1:<br/>
Input: s = "()"<br/>
Output: true<br/>

Example 2:<br/>
Input: s = "()[]{}"<br/>
Output: true<br/>

Example 3:<br/>
Input: s = "(]"<br/>
Output: false<br/>

### 解題思路
#### 利用stack的特性去丟向左的,碰到像右的就和最上的判斷,同一組就pop掉相消

```{r}
class Solution {
public:
    bool isValid(string s) {
        stack <char> tmp;
        for(char t : s){
            if(tmp.empty()) tmp.push(t);
            else{
                if((t == '(') || t == '[' || t == '{') tmp.push(t);
                else{
                    char a = tmp.top();
                    if((t == ')' && a == '(') || (t == ']' && a == '[') || (t == '}' && a == '{'))tmp.pop();
                    else return false ;
                }
            }
        } 
        return tmp.empty(); //注意不能直接return true 要防止只輸入1個的
    }
};
```
